# CakeStore UI Design Gallery & Mockup Assets

All generated UI mockups, architecture diagrams, brand logos, color themes, and reference layouts are collected in this directory for easy reference.

---

## 📁 File Catalog

### 1. Platform Core Views
- **`01_saas_marketplace_landing.jpg`**: Main public SaaS marketplace landing page (`/`) with location search, featured bakeries, SaaS onboarding pitch, and pricing tiers.
- **`02_customer_storefront_website.jpg`**: Branded bakery storefront website (`sweetdelights.cakestore.com`) with hero carousel, category pills, bestsellers catalog, "Our Story", and slide-out cart.
- **`03_owner_dashboard_and_kanban.jpg`**: Shop Owner Dashboard featuring live Order Pipeline Kanban (`Pending` $\rightarrow$ `Preparing` $\rightarrow$ `Ready` $\rightarrow$ `Completed`), revenue metrics, customer CRM, and store CMS.
- **`04_platform_admin_panel.jpg`**: Super-Admin control center for platform revenue KPIs, registered shops directory, status moderation (`ACTIVE`, `INACTIVE`, `SUSPENDED`), and subscription plans manager.
- **`05_frontend_architecture_diagram.jpg`**: End-to-end frontend routing and multi-tenant subdomain resolution architecture.
